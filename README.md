# 🚛 Fleet Health & Vehicle Efficiency Dashboard

## 📊 Project Overview

This Power BI dashboard provides an interactive analysis of fleet performance, vehicle efficiency, fuel consumption, maintenance costs, breakdowns, service compliance, and route operating costs.

The dashboard helps fleet managers identify inefficient vehicles, high maintenance costs, frequent breakdowns, overdue services, and expensive routes.

---

## 🎯 Project Objectives

- Monitor overall fleet performance
- Analyze vehicle fuel efficiency
- Identify vehicles with high maintenance costs
- Analyze breakdown frequency and reasons
- Identify overdue service risks
- Analyze route-wise operating costs
- Support data-driven fleet management decisions

---

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Cleaning
- Data Visualization

---

## 📌 Key KPIs

- Total Vehicles
- Total Fuel Consumption
- Average Fuel Efficiency
- Total Maintenance Cost
- Breakdown Count
- Service Compliance
- Operating Cost
